# G02 — Final 450-DOE ML Experiment and Results
**Date:** 2026-11-05. **Status:** Completed experimental comparison; held-out test evaluated once, no further model tuning planned. **Primary evidence:** user-executed notebook `ML (11).ipynb` (16 cells, Sections 1–10). **Do not confuse with the superseded V1/V2 ML experiments.**

## Executive summary
We trained ML surrogates for simulated HBM TSV **Maxwell capacitance matrix** elements in femtofarads from 450 distinct Ansys Q3D designs. Model inputs: substrate resistivity `rho_ohm_cm`, TSV diameter `D_um`, pitch `P_um`, height `H_um`, oxide thickness `tox_um`, and, when pooled, topology. `gap_um = P_um - D_um - 2*tox_um` is exactly derived; the final selected representations used five physical features and excluded gap. GSG yields C_AA only; GSSG and GSGSG yield C_AA, C_BB, C_AB. The matrix is assembled as [[CAA,CAB],[CAB,CBB]] for two-signal topologies. **Q3D is a simulation reference, not experimentally measured ground truth.**

The observed final test leaders **by topology** were:
- **GSG:** 3-seed MLP *prediction ensemble*, CAA MAE **2.066275 fF**, NMAE **0.059548**, R² **0.976115** (23 held-out cases).
- **GSSG:** pooled target-wise SVR, average component NMAE **0.067763**, mean R² **0.987502** (23 cases).
- **GSGSG:** pooled target-wise SVR, average component NMAE **0.050801**, mean R² **0.988971** (22 cases).

**Critical interpretation:** these leaders are observed on the final test set. Selecting a new topology-dependent hybrid based on test results would invalidate the test as an unbiased post-selection estimate. For a single deployed baseline, the pooled SVR is one topology-aware prediction interface implemented by *three target-specific regressors* (CAA trained on 315 training DOE, CBB and CAB on 210 training DOE each). This is **not** one single three-output SVR. Use the three-model topology-specific comparison and GSG MLP ensemble as important ablations; report all candidates transparently. The pooled SVR uses the **fixed Section 9** SVR parameters C=100, gamma=0.3, epsilon=0.01, **not independently tuned pooled parameters**.

## Source data, quality and provenance
- Data source: `G02_FINAL_ML_450_ALL_SELECTED_R.csv`, generated from the G02 Q3D final selected-R process, 450 distinct DOE: GSG/GSSG/GSGSG 150 each; resistivity 1/10/100 Ω·cm balanced within each topology.
- 450 selected-R native Maxwell matrix labels, not mixed across different runs. R count: R1=5, R2=3, R3=275, R4=2, R5=162, R6=3.
- `passwise_C_LT1` true for **447/450** (per-component adjacent-adaptive-pass change <1%); approved exceptions **DOE0099, DOE0233, DOE0321** are GSGSG R1 with ΔCAB approximately 1.156%, 1.321%, 1.250%, respectively. All three fell in *training* in this split.
- These criteria describe **numerical last-pass stability**, not absolute simulation accuracy or comparison against measured devices. Native matrix extraction frequency is 1 GHz in the CSV provenance; prior exported text frequency-header discrepancy should not be silently treated as resolved.
- Dataset includes source provenance and numerical quality columns. Do not train on selected_R, mesh metrics, run IDs, case IDs, DOE_ID or capacitance targets as input features.
- The exact final input CSV and final frozen split CSV must accompany the executable notebook for standalone re-running. Notebook reads CSV from a path defined by its first cell; it does not embed the full dataset.

## Reproducible data split (new experiment, not V1/V2)
Random-state seed **2026**; stratification by topology × resistivity. **315 train / 67 validation / 68 test**, generated using two `train_test_split` calls (first 70:30, then temporary split 50:50 with seed 2027) and saved locally as `FYP_ML_FRESH_SPLIT_2026.csv`. Training per topology 105. Validation GSG=22, GSSG=22, GSGSG=23. Test GSG=23, GSSG=23, GSGSG=22. No test labels used for tuning; however, previous historic V1/V2 experiments used the broader same 450-DOE source dataset, so do not claim a fully independent external validation dataset.

## Sections and methodology
1. **Data QA:** shape, identifiers, missing structural targets, per-topology/ρ balance, convergence provenance.
2. **EDA:** feature and target distributions; self/mutual correlations; observed geometric identity for gap (max error 3.55e-15 µm); no removal solely from EDA.
3. **New frozen stratified split:** 315/67/68, seed 2026.
4. **Preprocessing diagnostics:** train-only descriptive statistics; raw/log10 resistivity; Standard/MinMax/Robust scaling. Pipelines fit transformers inside each CV training fold.
5. **Controlled preprocessing search:** 72 options = 3 topologies × 2 ρ representations × 2 sets (five/six physical features) × 3 scalers × 2 baseline algorithms (Ridge and RBF SVR). Five-fold KFold shuffle seed 2026. Best tested representation: GSG raw ρ, others log10 ρ; five features; MinMax for SVR. Preprocessing choice depends on the tested algorithm/configuration, not a physical necessity.
6. **Algorithm screen:** Dummy, Ridge, RandomForest, ExtraTrees, SVR, MLP(16,), MLP(32,16); 105 CV fits. SVR strongest initial average CV scores: GSG 0.12094; GSSG 0.18100; GSGSG 0.15922 normalized MAE.
7A. **SVR grid:** 90 configurations/topology, 1350 CV fits, C ∈ {0.3,1,3,10,30,100}, gamma ∈ {0.03,0.1,0.3,1,'scale'}, epsilon ∈ {0.02,0.1,0.3}.
7B. **SVR boundary refinement:** 36 configurations/topology, 540 CV fits, C ∈ {30,100,300}, gamma ∈ {0.15,0.3,0.6,1}, epsilon ∈ {0.005,0.01,0.02}. Best observed SVR configurations below. CV minima are *optimistic selected estimates*, not unbiased post-tuning CV.
7C. **Extra Trees tuning:** 24 combinations/topology, 360 CV fits; min_samples_leaf {1,2,4,8}, max_depth {4,8,None}, max_features {0.6,1.0}, 200 trees.
7D. **MLP stability:** 2 architectures × 2 α × 2 learning rates × 3 seeds × 3 topologies × 5 folds = **360 fits**; 42 convergence warnings. Early stopping uses only sub-splits of each CV training fold.
8. **Held-out development validation:** 67 DOE, CV-selected configurations. **MLP 3-seed average of metrics is not the prediction ensemble.** GSSG seed 2027 was unstable (NMAE 0.23555).
9. **Architecture ablation:** topology-specific vs pooled *target-wise* SVR with matched C=100, gamma=0.3, epsilon=0.01 and same 5 folds, using training-only data. OneHotEncoder topology; MinMax physical input; StandardScaler target; GSG structurally missing CBB/CAB is excluded rather than zero-filled.
10. **Final held-out test:** 68 DOE. Tuned topology-specific SVR vs fixed-parameter pooled SVR on all topologies; GSG additionally uses 3-seed MLP prediction ensemble. **Model fitting in Section 10 is on the 315 training rows, not train+validation**, a crucial reproducibility note. Test was evaluated; no more post-test tuning.

## Scientific interpretation / limits
- **Interpolation within generated DOE**, not verified extrapolation, unseen topology, measured-device accuracy, or physical causal insight.
- Strong pooled self-capacitance improvement is consistent with transferable shared geometry trends; **not proof** of a specific electrostatic mechanism.
- Adjacent-pass ΔC is solver convergence evidence, not full validation of material/bias/frequency model. Semiconductor MOS accumulation/depletion/inversion/voltage-bias effects are not established by this electrostatic dataset; no claim of bias-conditioned prediction.
- No separate physical-constraint audit (positive-definite Maxwell matrix / diagonal dominance / sign consistency) was performed in this final notebook; **remaining check**, not established outcome.
- No final serialized trained model (`.joblib`) exists in the notebook artifacts reviewed. Section 10 trains in memory and exports CSV metrics/predictions only if the notebook is rerun.
- Need be precise about selection: model comparisons on test were performed, so any *newly chosen* hybrid based on test requires an untouched external set to support an unbiased post-selection claim. The pooled model was investigated prior to testing in Section 9, but its designation as final system was discussed after observing test data.

Caption note: NMAE and mean R² are averaged across available targets with train-median normalization; not percentages of individual coefficient errors.
